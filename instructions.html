Spectrum Tokens booklet

A step-by-step guide to generating color scales, reviewing semantic roles, matching reference colors, and exporting production-ready token files.

Step 1

Start with the primary color

Open Spectrum Tokens

Use Spectrum Tokens in your browser and start with the primary color controls at the top of the page.

Choose a primary color

Use the color picker or type a valid 6-digit HEX value. Spectrum Tokens validates the field and regenerates the palette as the color changes.

Save useful primary colors

Use the plus button next to the primary color field to save the current color. Saved swatches appear only after at least one color is saved.

Reuse or remove saved colors

Click a saved swatch to make it the active primary color. Hover or focus a saved swatch, then use the small remove control to delete it.

Step 2

Generate and tune the scale

Light tint reach

Controls how far the scale moves toward lighter tints.

Dark shade reach

Controls how deep the darker stops become.

Page theme

Switches the app preview between light and dark theme tokens.

Scale depth

Use Web for the default 7-stop system, or choose 8 or 10 for deeper exports.

What changes?

Spectrum Tokens regenerates yellow, orange, red, magenta, purple, blue, cyan, green, and grey primitive rows. Grey remains tied to the active primary and theme so neutral tokens belong to the palette.

Step 3

Review semantic roles

Read the tone strip

The tone strip shows the 300 stop for each visible-spectrum row. Use it as a quick scan for balance across hues.

Review the semantic preview

The preview shows success, warning, error, info, note, metrics, and palette rail examples using generated role colors.

Check role swatches

Primary, secondary, accent, note, info, success, warning, and error swatches show the semantic aliases used by exports.

Watch secondary and note behavior

Secondary is generated from the polar opposite primary hue. Note is mapped to purple-300 so guidance states stay visually distinct.

Step 4

Copy values from swatches

Open a swatch menu

Click a role or spectrum swatch. The menu title shows the active token name, then lists copy actions.

Choose the value format

Copy token name, HEX, RGB, CSS variable, CSS property, SCSS variable, or SCSS property depending on the workflow.

Use Color Match when needed

The same menu can open the color match modal for the selected swatch.

Step 5

Match a color to local Pantone definitions

Open Color Match

Use the primary field Color Match button, or open it from a swatch copy menu.

Review ranked matches

The modal compares the active HEX color to local reference definitions using Lab D65 values and CIEDE2000 distance.

Apply strong matches

Excellent and Close results include an eye action. Use it to apply that match as the primary color and close the modal.

ExcellentDelta E <= 2. Best digital reference fit.
CloseDelta E <= 5. Strong candidate for exploration.
CompatibleDelta E <= 10. Related, but should be reviewed carefully.
DistantDelta E above 10. Not a strong match.

Reference note

Color matching is a digital approximation. Use licensed Pantone workflows, print proofing, and vendor review for production ink decisions.

Step 6

Export production tokens

CSS

Global CSS custom properties.

SCSS

Organized _palette.scss partial with maps, helpers, and variables.

JS

Role, spectrum, and semantic token objects.

JSON

Design-token-oriented JSON with light and dark modes.

Figma

Figma-compatible token JSON.

Tailwind

Palette config object for Tailwind workflows.

Select a tab

Choose the export format from the tab list. The output panel updates immediately.

Copy or download

Use the toolbar copy action for clipboard workflows, or download the current export as a file.
